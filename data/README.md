# Data

- **Synthetic data**: frozen in `benchmark_comum_v1/dados_congelados.npz` and `dados_grandes_congelados.npz`
  (identical copies in `ppmt_pymgt_v1/benchmark/`; SHA-256 in `dados_sha256.txt`). They are fully defined by
  Eq. (8) of the paper and the seeds listed in the main README, and can be regenerated by `motor.make_data()`.
- **Jura** (Atteia et al., 1994; Goovaerts, 1997): 259 prediction points (Cd, Ni, Zn known) and 100 validation
  points (Ni, Zn known; Cd used only for evaluation). Not redistributed here, because the licence of the original
  data set is not stated explicitly. Run `python data/fetch_jura.py` to download it from the gstat distribution;
  the script writes `jura_real/dados/jura_train.csv` and `jura_validation.csv` and checks their SHA-256 against
  the files used in the paper.
