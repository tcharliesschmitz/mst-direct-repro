# mst-direct 2.0.0 — Matching for Structural Transport: reproducibility package

DOI: https://doi.org/10.5281/zenodo.XXXXXXX · Code: MIT · Data and results: CC BY 4.0 (see `LICENSE-data.md`)

Companion archive of the article *Matching for Structural Transport: preserving complete multivariate
tuples in conditional geostatistical simulation* (T. B. Schmitz; submitted to Computers & Geosciences).

## What MST does

Matching for Structural Transport (MST) simulates multivariate spatial fields by assigning **complete
multivariate tuples** (e.g. Cd–Ni–Zn vectors) to the positions of a spatial reference field. The reference
field is a Gaussian field generated by FFT-MA and conditioned by kriging/cokriging; the assignment solves an
entropy-regularized optimal-transport problem on a sparse candidate set (Sinkhorn), followed by rounding and
repair into a **bijection**. Because each realization is a permutation of the tuple pool, the empirical joint
distribution of the pool is preserved exactly, and complete conditioning tuples are honoured exactly.

## Installation

Python 3.10 (tested with 3.10.12 on Linux x86_64):

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python data/fetch_jura.py          # Jura data (needed for Tables 3/4, ablation and Figs. 5-7)
```

The `mst_direct` package can also be installed on its own: `pip install ./mst_direct-2.0.0`.

## Reproducing the paper

```bash
python run_all.py quick      # ~3 min: unit tests + Table 5 (MST rows) + one Jura seed
python run_all.py all        # everything (~1 h on 2 threads)
```

| Result in the paper | Command | Output (in `outputs/`) | Approx. time* |
|---|---|---|---|
| Unit tests (65) | `python run_all.py tests` | console | 10 s |
| Table 2, synthetic benchmark (4 methods) | `python run_all.py table2` | `table2_summary.csv` | 1–2 min |
| Tables 3–4, Jura nested validation and historical split | `python run_all.py table3_4` | `table3_4_*.csv` | ~25 min |
| Jura ablation: reference field alone vs. MST (MAE 0.445 → 0.406) | `python run_all.py ablation` | `jura_ablation.csv` | ~2 min |
| Table 5, interval calibration and comparators | `python run_all.py table5` | `table5_*.csv` | 1–2 min |
| Figures 1–8 | `python run_all.py figures` | `figures_scripts/output/` | <1 min |

\*Desktop workstation, 2 threads. Each step prints the maximum absolute difference between the regenerated
table and `results_reference/`. `table5` needs `table2` first (it reuses the PPMT fit); `figures` needs
`table2`, `table3_4` and `table5`.

## Notes

- All randomness is seeded; results are deterministic for a given environment (`requirements.txt`).
- The comparators are local implementations (Gaussian copula + FFT-MA, sequential Gaussian simulation with
  32 neighbours) and pymgt with a documented tail adapter; they are not the original GSLIB/CCG executables.
- Scripts write into their own `resultados/` folders inside this package and into `outputs/`.
- `figures_scripts/gerar_figuras.py` is used as a source of plotting blocks by `gerar_restantes.py`.
